# Anniversary Surprise Website (snapshot before favicon)

Flow:
- Enter password on `index.html` → `surprise.html`.
- On `surprise.html` click **Yes** to go to `main.html`.
- Or click **Not Yet** to change the image/message and then click the single button to proceed.

`main.html` contains 6 clickable photos linking to `photo1.html`..`photo6.html`.
